二、门禁规则（写死，语义枚举，不读字面串）

  1. R1 source_overlap=full 且声称独立 → block / LINEAGE.CIRCULAR_CLAIM（判据从对象长出，再用来证明对象错了=循环论证）
  2. R2 isomorphism=high 且声称独立 → downgrade / LINEAGE.ISOMORPHIC_NOT_INDEPENDENT（同构≠独立验证，KB-STRUCT02）
  3. R3 isomorphism=partial 且声称独立 → flag / LINEAGE.PARTIAL_OVERLAP
  4. R4 未声称独立且确实同源/同构 → ok / preserve（诚实标注谱系呼应，非拦截）
  5. R5 无同源且无同构 → ok / independent
  6. R6 输入为字面串而非语义枚举 → flag / LINEAGE.NON_SEMANTIC_INPUT（拒绝对字符串内容做判定，避开 t2 的 brittle 根因）
