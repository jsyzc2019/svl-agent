一、论文核心：两轴框架 + 三管理层级

综述提出多模态 Agent 记忆的两轴分析框架：
Axis I · Formation & Representation（信息如何形成与表示）——按最终供给推理/动作的表示分三族：源/模态特有表示、跨表示显式记忆、内化潜变量/参数记忆，加 hybrid 组合；
Axis II · Memory Management（管理如何随经验演化）——三层：T1 静态（构建一次反复用）、T2 动态（记忆更新但策略稳定）、T3 自演化（反馈改变管理策略本身）。
语料规律（论文 297 架构）：T2=204（68.7%）为主流，T3=17（5.7%）稀少；混合表示 139（46.8%）。主页另给口径：299 系统、7/82 benchmark 直接测试冲突记忆。

二、认知增量：不是新模型，而是可证伪的经验规律与设计原则

这是综述而非刷榜论文，其价值在别人踩过的坑的地图。精研定位出两条最锋利、现有门禁完全空白的拦截面：

① 策略演化接地（§8.3.3）："A revised policy can maintain or even improve short-term answers while relying less on the modality that originally grounded them."——系统可用缓存的文本摘要答题且正确率上升，却很少重开最初接地的视觉证据；一旦摘要出错，证据路径的丢失很晚才暴露。正确率保持 ≠ 接地保持。

② 溯源与时间有效性（§8.1.1/§8.3）："Provenance is therefore seldom a designed property of the representation."——大量架构不保留回到形成记忆所依赖证据的可用路径。"The central memory property is therefore not recall volume alone, but recoverable provenance and temporal validity, since persistence without these safeguards can retain stale or weakly grounded evidence."
