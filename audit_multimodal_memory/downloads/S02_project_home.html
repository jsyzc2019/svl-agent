What the corpus shows

  1. 68.2% of systems update memory through a stable management policy (T2).

    T2 Dynamic Memory is the norm. Only 17 systems let feedback change the policy itself.

    See the tiers

  2. 46.8% of systems are hybrids.

    Most pair explicit records with source-level evidence or modality-specific encodings.

    See hybrid patterns

  3. 17 of 17 self-evolving systems keep explicit memory.

    Policies evolve where memory can be read and edited; none of the source-only or latent/parametric-only systems do.

    See the matrix

  4. 7 of 82 benchmarks directly test conflicting memories.

    Evaluation favors finding old evidence over resolving conflicting or outdated memories.

    See benchmark coverage
