三、金矿：GUARD 三件事几乎是本仓诚实墙的论文版

"separates newly broken behaviors from remaining gaps and pins working rules" + "promotes an edit only when gains outweigh regressions" + "logging rejected edits so bad changes are not repeated"

新破坏（fresh regression）优先于未解决（unsolved gap）§4S25 P0 补洞"静默 continue 吞失败"、§4S36 词表污染查根因恢复——改动先问"新破坏了什么"，再看"还剩什么没解决"同构（行为先于口号）

四、必须讲清的根本分歧：非回归"保证" vs 零副作用"不声称充分"

GUARD 用 Theorem 1 给出门控后 self-review 分数在每轮 gated buffer 上单调不减的数学保证；本仓恰恰拒绝把"零副作用"当充分证明：

  • 本仓的"权威态零副作用"是每次实测的字节核验（result.json=0f3ccb13…、宪法 fe56291b… 未动），不是从机制推出的保证；一旦下一轮改动它可能对，所以每轮重验。
  • 本仓有 §4gz「有效性被夸大」的教训——用器官自己的命中数证明它有效是循环论证；GUARD 的 "19/19 non-regressive promotions" 若只数被门放行的样本，也需防选择性偏差（被拒的 6 个去哪了？门自己 abstain 的阶段怎么算？）。论文说 "FWT is zero because the gate abstained at later stages"——弃权被算作零负迁移，这在本仓纪律里只能标注、不能当成胜利（对应 V6 防 blanket abstention、V10 单一指标达标≠目标达成）。
  • 结论：GUARD 把非回归做成可保证的工程性质；本仓把零副作用做成每轮可证伪的实测纪律。前者强在形式化，后者强在不对自己已经"证明"的东西放过。不是谁更对，是目标不同。

五、可借鉴的真实缺口（未擅动，等授权）

  1. "新破坏 vs 未解决"的显式分类诊断：本仓有 `root_cause_trace`（查根因）和拒绝台账，但没有一个只读探针把"这次改动新破坏了什么"与"原来就没解决什么"分开统计——GUARD 的 Δ_hurt 正是这个。可做成 regression_vs_gap_probe()，纯只读。
  2. 拒绝台账的"不重复"可勾稽：本仓拒绝/self-bite 散在各轮 §4S 与 result 的 self_bites，没有一份"已拒改动"的机械清单防重复踩坑。GUARD 的 rejected-edits ledger 可借鉴为一份只读去重索引。
  3. 把"弃权率"作为显式指标：本仓有 V6 blanket-abstention 告警，但没有像 GUARD "gate abstained at later stages" 那样把门弃权单独计数并接受复核。可作为门禁就绪度探针的扩展字段。
