二、核心判断

不是"认知债务很可怕"，而是一个可迁移的独立拦截面。 Anthropic 官方研究里那句 paradox of supervision：用 AI 需要你有能力监督它，而监督所需的编码技能正被你用它这件事磨掉。Addy 把它拆成认知投降（AI 输出变成你的输出，无独立观点可比）、理解债务（代码涨得比团队脑里的系统理论快）、意图债务（why 只能来自人，agent 只会编合理理由）、编排税（你是不可并行的 GIL）。还有最易忽略的一层：把"有人读过代码/测试全绿"当成"系统正确"——Claude Code 自己承认连 revert 上升时自动收紧审批的断路器都还没有。本仓 20 道门禁判了单次评审漏斗、judge 独立性、服务口径、证明范围、接口控制，却无一判评审者是否还具备独立判断能力。

一手可核：实验/实践一手数字与原话：Shaw-Nave 三预注册实验 N=1372/9593 trials、hidden-seed 随机化 AI 正确性、AI 错时 73% 接受、+25/-15pp、Cohen's h=0.81、错误后 confidence 仍升(经二手 abstract 转述)；Anthropic skill-formation RCT 52 工程师、生成式使用 comprehension 17% 更低(50% vs 67%)(经 Addy 博客转述)；Claude Code 官方 changes/day 2500→30000、revert 降 40%、'did a human read code 是 imprecise proxy'、'尚无 revert/incident 断路器'；Anthropic survey >50% 员工 fully delegate 仅 0-20%、'paradox of supervision' 原话。

scoped 与折扣：Osmani 8+来源同一作者谱系按 KB-STRUCT02 折为 1（cognitive surrender→comprehension debt→intent debt→orchestration tax 相互引用，单一论点家族）；博客观点无数据(thekb.eu 明标 without figures or studies)；SSRN 是 preprint 未同行评审且 abstract 经二手镜像(etcjournal 评 productive but incomplete)；Anthropic survey 自陈 privileged position；S01/X/Substack/SSRN direct 6+ 来源不可达标 unavailable。术语 cognitive debt 跨 Storey/Addy/MIT 共用须区分提出vs转述。

不可判定边界：评审者实际能力是否真被侵蚀、某流程的评审是否真有效、AI 错时接受率是否在真实工程场景复现——本门只判『能力前提是否诚实披露』，不承诺评审真有效(KB-R07/KB-AUDIT03 存在≠执行)；审读外部工程流程，不判本仓。
