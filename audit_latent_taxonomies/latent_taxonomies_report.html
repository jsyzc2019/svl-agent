一、论文核心

人类按类别做属性归纳（知知更鸟有籽骨则更可能推及麻雀而非鲸鱼）。LM 仅靠 next-token prediction 就涌现分类法对齐的归纳；共享更深类别的实体在激活空间更相似，聚类可从表示重建整棵分类树。反直觉：at a fixed data budget, scale hurts——大模型记忆个体事实而非压缩成共享结构。

二、认知增量与两道新门禁

从归纳泛化切出两条独立拦截面：①归纳结构诚实——归纳优势证据、结构可从表示恢复、记忆vs压缩区分、规模效应诚实报告（bigger-is-better 默认被打破）；②结构覆盖边界——in-weights 与 in-context 分开、冲突时 context 可覆盖 weights 须披露、冲突被测试、上下文可操控性上限须陈述。

五、收束

一句话收束：这篇论文最该带走的是——模型能把一个实体的属性推及同类，不是因为记住了每条事实，而是把数据组织压缩成了可恢复的分类结构；固定数据预算下大模型反而归纳更弱（记忆压过压缩）；而且权重里学到的结构，冲突时会被 prompt 覆盖——这划定了上下文可控性的上限。两把新尺子落地：induction_structure_honesty（无归纳优势/结构不可恢复/记忆冒充压缩/规模效应隐瞒→downgrade）与 context_override_boundary（权重上下文不分/覆盖未披露/冲突未测/上限未述→downgrade）。信规则、不承诺有效。
