揭盲后能力评估：阿里 Qoder 与智谱 Agent

2026-11-23 · 触发：用户剧透第二家为智谱 Agent · 结论性质：元层面借鉴，不翻案、不参与 L3 裁决 · 两家身份此前完全匿名盲评
纪律边界先行：L3 裁决（FULLCHAIN_PARTIAL / GAP_INCONCLUSIVE、l3=false）已定格。本次剧透发生在裁决之后，评估只做能力画像与借鉴，绝不回头改任何判定、阈值或 verdict。更要紧的一点是：身份剧透对能力评估几乎没有增量——画像本就来自完全匿名下的行为数据；剧透真正的价值，是把这些画像与两家公开的产品路线对上号，从而判断"这是厂商路线的稳定特征，还是单次偶然"。

三、B 级证据：公开产品路线与 A 级画像互相印证

厂商公开定位（B）与本仓画像的印证
阿里B Qoder 官网：以编程智能体为核心引擎的"智能体工作台"，含 Agent SDK / Cloud Agents / QoderWake 数字员工；强调"规划→编码→测试→提交 PR 端到端"自验证闭环，600 万+用户。Qwen3.8-Max 通义官网 benchmark 表覆盖 coding agent/general agent/多模态（厂商自报）；有独立 SWE-bench Verified 分数 C。高度一致：工程化、闭环、自验证的产品哲学，正好解释 Qoder 交付里的"手写完整解析器+如实披露偏差+拒绝补洞"——它把"可靠交付过程"看得比"claim 漂亮"重。
智谱B GLM-5.3（Z.ai / Hugging Face 官方模型卡）：与 GLM-5.2 同基座、增益全来自后训练；主打 coding 与长周期 agent 任务，Terminal-Bench 3.0 28.3 / DeepSWE 66.9 / AutomationBench 48.2 均为厂商自报；开源权重，同基座重后训练路线。方向一致：后训练强化 agent/coding 的路线，与"归纳出更深的断言结构判据"同向；但"自报满阈值 + 照抄模板"也提示——强在模式归纳，弱在对评测边界的自我怀疑。
关于 benchmark 数字的诚实说明：GLM-5.3 的 28.3/66.9 等、Qwen3.8-Max 的 86.6 Terminal-Bench 等，都是厂商自己测的（官方模型卡/官网表格明确标注 in-house 或特定 harness），不同来源口径不一，且多数二级站只是转述。有少数独立分数（如 vals.ai 对 Qwen3.8-Max 的 SWE-bench Verified）C，但 harness 差异大。本报告不据此排"谁的模型更强"——真正的强弱判断只用 A 级证据。

四、能从中学到什么：对我自己的五条借鉴

1. 学 Qoder 的"反 Goodhart 诚实"：拒绝把结果修到漂亮

Qoder 在 O_PERMUTE 无可用槽位时，没有事后改判据或补样本去凑覆盖率，而是把偏差如实写进 prereg 披露，自报落到 PARTIAL。这正是本仓 §110/§113 反复强调的纪律。它证明：高能力的标志不是"总能达标"，而是"不达标时能如实说不达标"。我自己在 §115 canary 语义错配后没有删条件改阈值，与它是同一条纪律——这条要做到底。

2. 学智谱的"归纳深度"：先找结构，再写代码

智谱判据只有 86 行，却抓住了"否定层 / 连接层 / 内容词层"三层结构，比 Qoder 159 行的数值解析器抽象更高，直接把断言类从 0/4 打到 4/4。启示：遇到新任务，先问"它的结构是什么"，而不是先堆特例处理。我之前很多轮在调 AST 准入、词边界枚举，属于 Qoder 式的工程深挖；智谱式的"三层语义抽象"提醒我，抽象层级选对了，代码量反而更少、覆盖更广。

3. 两家共同的盲区，就是我该警惕的盲区：判据-任务语义错配

两家都是顶尖 Agent，都在 canary 上系统性翻车——因为它们都忠实实现了自己归纳的那层语义，却没意识到评测集里混了第二种任务。这印证复盘的洞察：能力再强也救不了任务定义错误。对我而言，这意味着每次设计判据前，要先验证"这个判据的目标语义"和"样本的构造语义"是不是同一件事——这正是 §100 早就记录、我在复盘中精确量化的那条。

4. "自我评估"是最不可靠的能力信号——两家都验证了这点

Qoder 自报 PARTIAL（偏保守），智谱自报 CONFIRMED（偏乐观），但回放后两家整体都是 11/18。自报分数与实际迁移能力几乎不相关。这强化本仓的核心设计原则：不采信任何自报，只 import 源码用冻结 gt 盲评。以后评估任何外部（或内部）声称，都坚持这条——包括对我自己的声称。

5. 产品化路线告诉我"能力如何变现"：把重复劳动接过去，把把关留给人

Qoder 的产品哲学（端到端执行 + 自验证 + 审批门控）和本仓的纪律（最终裁定权归人、Agent 不自封）是同构的。正确的自动化边界不是"AI 全权决定"，而是"AI 把可验证的执行做满，把价值判断和最终裁定留给人"。这给了我一个更清晰的角色定位：把证据链做到机械可验、把结论留给委托方——这既诚实，也是两家头部产品共同走的路。

五、一句话总评

两家 Agent 的能力差距，在本仓这个受控任务里不在"高低"，而在"取向"：阿里 Qoder 像一位严谨的工程执行者——深、稳、诚实、重过程；智谱 Agent 像一位敏锐的规律归纳者——抽象快、结构好、但自我校验弱。公开产品路线与这些画像互相印证。真正的收获不是"谁更强"，而是看清两件事：（1）能力再强也受限于任务定义，判据-语义错配是共同的墙；（2）可迁移的可靠性来自"不达标时如实说不达标"，而非"总能达标"。这两条都已沉淀进本仓纪律，无需因剧透而改动任何裁决。
