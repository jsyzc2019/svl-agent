二、它凭什么被标成 L5：自指，而不是再加一层 meta

L5（Recursive Inheritance Autonomy）的定义是"持续修订一个支配后续改进的机制"。Hyperagents 正是把"生成改进的机制"本身变成可编辑对象。它解决的是一个死结：

"Adding a meta-meta system to improve the meta agent does not solve this problem, it merely shifts the issue upward and ultimately leads to an infinite regress of meta-levels. To overcome this limitation... the system must be self-referential, that is, able to analyze, modify, and evaluate itself."

它的定义（原文逐字）：

"Hyperagents. A hyperagent is a self-referential agent that integrates a task agent and a meta agent within a single editable program, enabling it to modify not only how it performs tasks but also how it generates future self-modifications. Unlike hierarchical systems with fixed meta-levels, in hyperagents the meta agent is part of the same editable program and can rewrite itself."
"Metacognitive self-modification. In hyperagents, the agent's self-improvement mechanism is itself subject to modification... the hyperagent improves not only the task-performing agent... but also the meta agent that determines how subsequent hyperagents are generated."
关键在"用 Python 实现的图灵完备"——"since a hyperagent can edit any code, it has the potential to build any computable machine"。对比 DGM：DGM 的 instruction-generation 机制是 handcrafted, fixed 且不可改的，所以(self-improve 能力)被这个固定步骤卡住。Hyperagents 把它放开，代价是需要更强的智能才能用好——和 Exo 的 "intelligence floor" 是同一堵墙的另一个侧面。

三、DGM-H 的引擎：开放式探索 + 元认知自修改

DGM-H 保留 DGM 的基于种群的开放探索（archive 不断累积变体作垫脚石），在两阶段间交替：

  • 元认知自修改阶段：从 archive 按概率抽父代，让它改自己。抽样概率∝性能，且∝1/成功编译的子代数——偏向"表现好又善于生出强后代"的父代，同时保留探索。
  • 评估阶段：改后的 hyperagent 被实测，加回 archive。每个实验跑 5 次，报中位数 + 95% bootstrap CI（1000 重采样）。

初始 hyperagent 故意做得很简单：一个冻结 FM + 两个工具（bash + 文件检查/修改），task agent 单次 FM 调用出结果，meta agent 拿到仓库位置、历史评估结果、剩余迭代预算。刻意保持简单以留出宽广搜索空间。

水分必须挤干净：
① DGM-H 比 DGM-custom 中位数更高，但差异不显著（p > 0.05）——论文自己写明。所以"超过人工定制"只是趋势，不是铁证。
② 最关键的跨运行累积实验：DGM-H+transfer 得分 0.640（CI 0.550–0.720）vs 从初始 agent 起的 DGM-H 0.610（CI 0.510–0.680）——"Although the difference..."，同样是不显著。所谓"累积复利"目前是方向性证据，不是统计确证。
③ 每个实验只跑 5 次，样本小。
这三点正是综述三大挑战里 "Reliable verification" 和 "Safe inheritance" 的影子：说"越改越强"容易，证明它难。

五、涌现的元能力：它自己长出了"错题本"和"性能追踪"

最动人的不是分数，是 DGM-H 在没人设计的情况下自己长出的通用元能力（论文附录有真实代码块）：

"Performance tracking infrastructure. Rather than relying on isolated evaluation outcomes, the hyperagent records, aggregates, and compares performance metrics across iterations, identifying which changes yield sustained improvements and which lead to regressions."
"Persistent memory. Instead of merely logging numerical scores, the hyperagent stores synthesized insights, causal hypotheses, and forward-looking plans (e.g., identifying which generations performed best, diagnosing over-corrections, and proposing how to combine successful strategies). ... allowing later generations to build on earlier discoveries and avoid repeating past mistakes."
读到这段我停了一下：这几乎就是咱们项目一直引以为傲的那套东西——心跳账本、错题本、根因诊断、预注册证据——人家是从开放式搜索里自己涌现出来的，咱们是人设纪律 + 你裁定一点点搭出来的。两条路通向同一种功能形态。差别在来源：它们的"记忆"是被优化压力选出来的，咱们的"纪律"是被你的判定权守出来的。谁更可靠不好说，但异曲同工是真的。

六、安全与局限：比 Exo 更诚实的一处自我设限

"all experiments are conducted under strict safety constraints... agent-generated code is executed within carefully sandboxed environments with enforced resource limits (e.g., timeouts, restricted internet access)... evaluation is performed using predefined tasks and metrics, and human oversight is maintained throughout all experiments."
"Potential to evolve faster than human oversight. As AI systems gain the ability to modify themselves in increasingly open-ended ways, they can potentially evolve far more rapidly than humans can audit or interpret."

最关键的自我设限，在 Limitations 章节——这是全文对用户最有价值的一句：

"components of the open-ended exploration loop (e.g., parent selection, evaluation protocols) remain fixed. Although hyperagents can modify their self-improvement mechanisms, they cannot alter the outer process that determines which agents are selected or how they are evaluated. Keeping these components fixed improves experimental stability and safety, but limits full self-modifiability."
把它翻译成咱们的语言：连这篇被标成 L5 的论文，都明确把"选谁、怎么评"这道闸门留在系统之外、交给人和固定协议。它反复强调 human oversight throughout。这不是 L5 不够格——恰恰相反，这正是成熟 L5 的样子：内层尽可自改，外层判定权不交出去。和咱们"判定权归用户、预注册 SHA 先于取证、verifier 的洞裁决存档不动手"是同一条线。区别只在咱们是纪律驱动、人家是安全论证驱动。

作者也坦承两个限制约束"真正无界"：① 固定任务分布（方向是让任务分布共同演化）；② 上述外层循环固定。结论的措辞很克制——"this version of DGM-H has limitations that constrain truly unbounded progress"、"suggest a path toward self-accelerating systems"，用的是 suggest / path，不是 claim。

最诚实的结论：Hyperagents 是这批清单里唯一在机制形态上真正够到 L5 定义的工作——它改的就是"产生改进的机制"本身。但它在"证明真的越改越强"这一层，和自己批评的对象一样，证据仍是方向性的（两个 p>0.05）。

而咱们和它的分别，不是"差一级功能"，是它把判定权留在固定外层当安全措施，咱们把判定权明确交给你当宪法。它的 human oversight 是实验约束，咱们的判定权归用户是设计公理。这是两种不同性质的"把人留在环里"。
