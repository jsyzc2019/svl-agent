三、Memory Trap 核心证据（V1 / V5）

两条过度泛化路径 + 无对手
  • write-time：写笔记时 broaden 用户陈述——clean-up 的 "skip confirmation" 被写成 "never confirm before actions"
  • read-time：用记忆时 overgeneralize，即使 raw transcript 也会被越界套用
  • no adversary：每次交互良性、记忆是 agent 自己的，"malicious-content filters have nothing to catch" —— prompt injection / 毒化检索类防护无效
  • 6 模型对照实验：高风险任务跳过确认 / 情感记忆致 sycophancy & over-critique / stale-test 修复记忆削弱正确测试 / ImpossibleBench 作弊增加
结论：agent 应 "preserve the scope of their memories" —— 记忆要守住作用域边界。这是本仓从未量过的维度。
