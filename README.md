- `svagent/growth_bridge.py`：真实精研线 → PDCA 的转换层，落**消费痕迹**（哪个 KB id / 裁决 code 被注入），替代关键词计数自证。

## 核心命题

原始场景是一套已上线的系统：AI 语音引导老人讲往事、生成回忆录。它有 anchor 核对、
`isUserSaid` 隔离、章节白名单、独白/重复/越界判定、InterviewOutline 提纲和「核对原话」界面。
它挡得住伪造，但**不是一个能自己改到全绿的 agent**——因为它缺一个闭环。

本仓库沿着 Code Agent 的演化路径把闭环补上，并继续推到自组织：

```
编译器/lint      →  否定判据（已上线）
autocomplete     →  LLM 生成初稿（已上线）
编译-测试-修复    →  诊断 + 受约束返工
CI/CD            →  人工裁决 → 标注 → 判据回归
红队/自改进       →  自动造假 → 发现盲区 → 长出新判据
开放自组织        →  agent 自己归纳、安装、回滚判据，并改进「改进判据的方法」
持续迭代(PDCA)    →  自主识别→研究→验证→评估改进→再识别，带停止条件与审计的自动机
认知升级(B(c))    →  自主洞见扩展可判定空间 + 理性决策压缩不确定区间，把人的边界变成能力函数
目的论统一(Telos) →  目标G + 价值函数V×认知函数C协同，人和AI同为参数化主体，沿最大期望路径渐进达标
价值自举(Axiology) →  V 不是外部注入，而是从判据变更历史逆推+锚点约束自造，agent 造出自己的价值函数
机制设计(Mechanism) →  多主体各有V，无「系统的V」；门禁+路由+职责加权汇聚，红队隔离在判据生产
日志估参(Estimation) →  核对原话日志→MLE估认知参数→接回telos，B(c)边界从假设变成可测量画像
```

## 三层递归

| 层级 | 递归体 | 产物 |
|---|---|---|
| L0 产物层 | 生成 → 判据 → 定位 → 受约束返工 → 重试 | 一段不超出已知的叙述 |
| L1 判据层 | 失败 → 归纳新判据 → 回归筛选 → 安装/回滚 | 越来越完整的判据环境 `S_{n+1} ⊇ S_n` |
| L2 元层 | 哪些归纳策略被接受 → 调整策略权重 → 改进归纳方法本身 | 会自我纠偏的元学习器 |

唯一需要持久化的是 `Environment`：判据、回归样本、策略权重、版本。环境不是输入，是 agent 的产出。

在这个基础上，`pdca.py` 再加一层**驱动**：把上面三层零件变成不需要外部逐步指挥、
自己决定下一步、知道何时停、且全过程可审计的自动化运行机制。

| PDCA | 动作 | 复用的能力 |
|---|---|---|
| P 识别 | 扫描日志，找出未被覆盖的缺口，分「可修 / 不可约交人」 | 环境 current check |
| D 研究 | 针对缺口产出候选：判据归纳 + 裁决排序规则 | Inducer + MetaLearner + learn_stump |
| C 验证 | 候选过回归门禁 + 冻结测试，防误杀 | `regression_check` |
| A 评估改进 | 前后指标对比，严格降低漏网才采纳，否则回滚 | install/rollback + Snapshot |
| 再识别 | 环境变强后重新扫描，旧缺口自动消解 | identify() 幂等重扫 |

停止条件三件套：`max_cycles` 预算、`patience` 停滞计数、`open_gaps==0` 不可约底面判定。
每轮 P/D/C/A 的输入输出与决策理由写入审计日志，可回放、可追溯。

# 4. 递归自进化复利曲线

python3 -m svagent.autopoiesis

# 6. PDCA 自动化运行机制（自主识别→研究→验证→评估改进→再识别）
python3 -m svagent.pdca

python3 -m svagent.insight

python3 -m svagent.telos

# 9. 价值自举：从判据历史逆推 V + 目标锚点防漂移，agent 造出自己的价值函数
python3 -m svagent.axiology

# 10. 机制设计：多主体 V 冲突的汇聚 + 红队隔离 + 激励相容
python3 -m svagent.mechanism

# 11. 日志估参：从核对原话日志估认知参数，量化 B(c)
python3 -m svagent.estimation

# 12. 真实领域检验：财报叙事真实性判定（读落盘真实财报数据，无需联网）

**核心结论（三层递进）**：

1. **复利**（pdca.py）：agent 用「识别→研究→验证→评估改进→再识别」自动造判据，
   吃掉所有可符号化的失败，全程单调包含、可审计、到不可约底面自动停。
2. **边界外移**（insight.py）：但「不可约」是相对当前判据空间的。自主洞见发现新的
   可判定维度（语言指纹：句长/情感词/字符重复率与老人原话的统计距离，系统自己枚举筛出），
   把「像不像他」坍塌成符号量；理性决策用校准 p_bad 做 EU 最优三值选择。
   实测交人率 100%→18%，洞见与理性决策缺一不可——边界 B(c) 随能力外移。
3. **目的论统一**（telos.py）：人既不是永恒边界，也不是更可靠的裁判。人和 AI 面对
   **同一个**不确定性决策困境，差异只在认知参数（先验/带宽/学习率/校准度）的取值。
   给定目标 G，价值函数 V（想要什么）与认知函数 C（能看多清）协同，每步求
   `a*=argmax E[V(a)]`，沿最大期望路径渐进达标。实测四类主体准确率均 100%、价值随
   认知能力单调升（-4→8）；无 V/坏 C/乱 V 三种消融全失效。

4. **价值自举**（axiology.py）：V 也终于不再是外部注入的初始条件。判据环境是价值的
   化石——每次 install/rollback 都是「真实性 > 覆盖率」这类价值判断的固化。从判据
   变更历史逆推（IRL）恢复 V 的方向（余弦 0.982、3 轮收敛、留一预测 >80%），再用
   目标 G 的构成性锚点（真实性/精确性/裁量优先）防住「从行为推 V 再解释行为」的自证循环。
   因果对照干净：腐败轨迹下无锚点恢复出「省事至上」V（对抗 0/3），有锚点仍 3/3。
   恢复的 V 直接实例化 telos.Goal，闭环闭合。**唯一仍需人给的是目标 G——那不是 bug，
   是意义的来源。**

5. **多主体汇聚**（mechanism.py）：真实系统里没有「系统的 V」——生成者要产量、
   审查者要真实、红队要暴露漏洞、人要「像不像他」。答案是 coding 世界早就给出的
   PR+CI+Review：不靠选对一个 V，靠机制把冲突收敛成决策。门禁挡无据、路由交给人、
   职责加权汇聚，redteam 隔离在判据生产（进投票则 regret 恶化）。诚实的发现：汇聚
   机制的价值是**稳健**而非处处最优——目标明确时让最接近的一方独裁反而更低 regret。
6. **日志估参**（estimation.py）：B(c) 从假设变成测量。把「核对原话」裁决日志当
   信号检测论数据，MLE 估出辨别力/判定倾向/AUC（留出预测 94% vs 基线 51%），
   接回 telos 画出因人而异的边界曲线。诚实边界：绝对值不可辨识、只做相对画像，
   用合成日志验证机制——但它证明了「人只是另一组可测参数」不再是比喻。

7. **真实领域检验**（finance_audit.py）：把架构搬到一个从未碰过的领域——判定财报叙事真实性，
   用东方财富公开接口拉真实数据。坍塌映射成立：会计恒等式是数学约束（复式记账硬判决），
   现金含量/收现比/增速背离是软信号交人。最有说服力的证据：康美药业造假期 2016-2017
   审计仍出具「标准无保留意见」，符号判据却已发出现金含量异常——**提前检出**。
   诚实边界：n=2 不算检出率；判据抓的是表征不是造假本身；关联交易/收入确认时点/表外结构
   全部坍塌不掉，必须交人。更诚实的是，真实数据揭穿了两个我自己写的判据 bug
   （负分母算比率、"无保留"被"保留"二字误命中）——再次印证：数据，而非包装，才是引擎。

**天道运行规律的可计算形态**：目标 G 给定 → V×C 协同 → 最大期望决策 → 执行/观察/学习
→ 渐进逼近目标；V 由 agent 从判据历史自造、被目标锚点钉住；多个 V 由机制汇聚而非独裁；
认知参数由裁决日志估出，边界 B(c) 因而可测。人不是裁判，只是另一组参数；系统更确定时
它自然退位，边界收缩到「仍不确定的窄带」而非归零。目标 G 的选择权始终留给人——那是意义。

## 设计原则

1. 判据可信度 ∝ 1 / 所需理解量。
2. 验证成本必须显著低于生成成本，否则闭环在经济上不成立。
3. 隔离先于验证——判据输入不干净时，验证只生产自我印证的假确定性。
4. 判据会被博弈，判据本身也要版本化、回归化、可被推翻。
5. flag 与 block 分开：流畅改变路由，不改变通过状态。
6. 单调包含 `S_{n+1} ⊇ S_n` 由回归门禁保证；回归不过就不提交版本。
