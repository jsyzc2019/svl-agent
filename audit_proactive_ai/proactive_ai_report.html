二、核心判断

不是"主动 agent 很重要"，而是一个可迁移的独立拦截面。 综述贡献的是分类学语言（6A / residual decision space / reactivity–proactivity 频谱），按 KB-STRUCT05"提出框架≠证明有效"打折；1410 被引、80 代表作、13 领域是综述规模口径，不是独立证据。真正的新牙是：一个主动 agent 声称"我主动做了 X"时，是否诚实亮出授权边界——①值得做的目标 ≠ 被授权的介入（Figure10）；②仲裁四关（置信/价值成本/时机/风险可逆）；③形式控制 ≠ 真实控制（agent 靠选信息/选项/默认项获实权）；④沉默选项与风险分级同意须披露。

本仓 19 道门禁判了证明边界、记忆作用域、训练服务口径、跨 run 续接、检索污染、调用接线……却无一判"主动介入的授权正当性"。尺子对象是任何主动 agent 声称——可迁移、会拦，符合 KB-META01。
