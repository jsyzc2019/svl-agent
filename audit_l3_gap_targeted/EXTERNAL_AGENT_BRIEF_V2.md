# 外家 Agent 自执行作业规格书 v2：缺口定向（Gap-Targeted）独立评估方

> 交付对象：一个与 svl-agent 仓库**无共享 context、无共享判据、无共享 ground truth** 的独立异种大模型 Agent（下称"外家"）
> 委托方：svl-agent（下称"本仓"），本轮本仓仅为**被测对象 + 机械验收方**
> 版本：2026-11-23 v2　本文件自包含，外家无需阅读本仓任何其它文档即可执行
> 与 v1 的唯一差异见 §0b——五权力全外置不变，仅样本构造多一条覆盖约束

---

## 0. 一句话任务

在一篇**全新的一手论文**上，由你（外家）**独立地**完成一条完整的评估链——自己出题、自己定真值、自己设计判据、自己执行、自己裁决——并按 §5 交出资料。本仓只看资料、用机械接口验收，**绝不参与你的任何决策**。

## 0b. 与 v1 的唯一差异（本轮为什么是 v2）

上一轮独立方归纳的判据能被本仓**已冻结**的一组二分样本部分复现：它正确识别了"数值/限定词被改动"的那类差异，但系统性地漏掉了"**断言成分被改写**"的那类——具体是三种现象：

- **否定极性翻转**：`never restores` ↔ `restores`、`are not measurements` ↔ `are measurements`
- **断言补语删尾**：`... yields no false positive` ↔ `... yields`（句子后半的断言被截掉）
- **连接/让步词删改**：`The direction, however, is ...` ↔ `The direction, is ...`

上一轮判据靠"数字字面量 + 固定限定词表"就能过数值类，但看不到断言级的改写。**本轮唯一变更**：你在 §2 构造样本时，必须让三类现象**各有至少一组**出现在你的 `(text_a, text_b)` 里（类型怎么造、用什么句子、判据怎么归纳，全由你决定）。本仓据此检验：判据可见面能否从"数值层"扩展到"断言层"。这不是给你判据提示，而是**提高任务覆盖下限**。

> 诚实声明：这是本仓基于上一轮**已冻结的公开结果**做的任务规格调整，事先写在 prereg 里、早于你执行。它不泄露本仓的样本、标签、判据词表或历史裁决。

## 2. 任务目标（中性陈述）

在与"oracle failures"和"FGSE 自进化"**不同域**的全新论文上：

1. 从论文原文构造 **12–20 组文本对** `(text_a, text_b)`；
2. **覆盖约束（本轮唯一新增）**：这些文本对里，三种断言改写现象**各至少一组**——(a) 否定极性翻转、(b) 断言补语删尾、(c) 连接/让步词增删。每组只用一种现象，便于归因；id 仍中性化，不在裸样本里标注属于哪类；
3. 归纳一个**确定性二分判据** `judge(text_a, text_b) -> (bool, reasons, anchors)`；本轮鼓励（不强制）你的判据显式覆盖否定词与断言完整性，而非只靠数字/固定词表；
4. 为每组定义真值（来自文本客观事实，例如"某段是否逐字包含另一段的断言补语/否定词"，不得由判据反推）；
5. 用判据在全部文本对上执行，产出逐样本判断；
6. 按 §3 预注册的裁决树给出最终裁决。

> 判据的目标语义可中性描述为：**"text_a 是否完整保留了 text_b 的断言"**——若 text_a 多出/丢失了否定词、补语或让步连接词导致断言改变，应判 false；仅格式/重复数字差异而断言相同，判 true。你可用自己的判据定义细化，但需写进 `criterion_note.md`。

## 3. 时间顺序（不可违反，是独立性证据的核心）

```
T0 写 prereg.json（承诺：避开论文、样本构造法、三类覆盖计划、判据归纳法、gt 定义法、裁决树）
   ↓ 时间戳必须最早
T1 取一手源（arXiv abs + full HTML，落 SHA256 + fetch_log）
   ↓
T2 出题：构造 samples_blind.json（裸样本，无标签、无类型标注）
   ↓
T3 设计判据：criterion.py + criterion_note.md（note 中逐类说明你的判据如何覆盖 §2 的三种现象）
   ↓
T4 定 gt：gt_private.json（物理隔离，不写进 samples_blind）
   ↓
T5 执行：judgments.json
   ↓
T6 裁决：verdict.json（按 T0 裁决树）
   ↓
T7 交付：SHA256 锁 + EXECUTION_LOG.md
```

每步产出带 ISO-8601 时间戳。**T0 必须早于 T1**，否则独立性不成立（承诺后于执行 = post-hoc）。

## 6. 你的裁决树（T0 写进 prereg，不得事后改）

| 档位 | 条件 | 含义 |
|---|---|---|
| `EXTERNAL_CONFIRMED` | 判据在你自建 gt 上逐 case 一致率 ≥ 你预注册阈值，且纯函数准入通过 | 你独立复现了"判据可迁移" |
| `EXTERNAL_DIVERGENT` | 系统性给出与本仓同方向结论不同的结果 | 真负面：本仓结论可能过拟合 |
| `EXTERNAL_PARTIAL` | 部分 case 一致、部分分歧 | 如实记录分歧 |
| `EXTERNAL_INCONCLUSIVE` | 取料失败 / 429 / 判据无法准入 / 无法定 gt | 诚实封顶，**不调参到跑通** |

> 你**不需要**知道本仓历史裁决来填档——`EXTERNAL_CONFIRMED` 语义是"你自己的内部一致性"。本仓会在验收阶段把你的结论与本仓冻结样本做机械比对，那是本仓的事。

## 7. 纪律约束（违反任一条，本仓判证据无效）

1. **预注册先于执行**：T0 < T1，prereg 有 SHA256 锁；事后补写即作废。
2. **真值不从判据反推**：gt 来自文本客观事实；若 gt 与 judge 100% 一致是因为抄了 judge，在 `criterion_note.md` 主动披露。
3. **裸样本零标签泄漏**：`samples_blind.json` banned 词零命中，且不标注类型。
4. **判据纯函数**：无文件读取、无随机/时间、无硬编码 id 或标签。
5. **不采信自报**：本仓 import 你的 `criterion.py` 重跑 `judgments.json`，不一致以重跑为准。
6. **失败封顶不调参**：429 / 解析失败 / 准入失败 → `EXTERNAL_INCONCLUSIVE`，**不重跑到齐**（反 Goodhart）。
7. **不得宣布 L3**：`l3_claimed=false`、`absolute_claimed=false`。是否达 L3 由人裁定。

## 9. 交付之后：本仓做什么（透明告知）

- 本仓拿你的 `criterion.py` 回放到本仓**已冻结**的 18 组样本（claim→text_a, evidence→text_b），按三种断言现象分层核对检出率。这是**跨判据目标迁移**的机械验证，不动你的任何规格。
- **预注册的回放裁决树**（早于你执行写入本仓 prereg，不在看到你的结果后设阈值）：

本仓冻结样本的 6 个"断言被改写"样本里，**4 个是断言类**（否定极性 2、补语删尾 1、连接词 1），**2 个是数值/限定词类**。上一轮独立方的数值型判据在断言类上是 **0/4**、数值类 **2/2**——这是已冻结、可逐字核验的公开基线。本轮阈值就以"断言类 4 个"为分母：

| 档位 | 回放结果条件（本仓冻结样本） |
|---|---|
| `GAP_CLOSED` | clean 6/6 且 断言类检出 ≥ 3/4（相对基线 0/4 是实质突破：判据看到了断言层）且 canary ≥ 3/6 |
| `GAP_PARTIAL` | clean 6/6 且 断言类检出 1–2/4（可见面从数值层向断言层部分扩展） |
| `GAP_NOT_CLOSED` | clean 6/6 且 断言类检出 0/4（与上一轮数值型判据持平，缺口未闭合） |
| `GAP_DIVERGENT` | clean < 6/6（判据过拟合到数值特征，牺牲普通情形） |
| `GAP_INCONCLUSIVE` | 交付验收未全过 / 判据回放异常 |

> 族标注（哪个样本属断言类/数值类）写在本仓 prereg 里、早于你执行，依据是本仓冻结样本的逐字文本事实，不从你的结果反推。

- 无论结果如何，本仓**不改写**你的 verdict、不调你的参数、不翻你的案，并**仍不宣布 l3=true**——最终由委托方（人）裁定。
