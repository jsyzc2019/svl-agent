五、V4 裁决：选择偏差为何不编译新牙

用被测 agent 反馈选 Lite 子集 → 再证排名稳健 披露充分
Lite 5 任务/轨用 original six agents 的 pairwise ordering 表现挑选（保序性最优子集），再用 Full-Lite ρ=0.93 论证排名稳健——存在'用被测对象反馈选子集→再证子集稳健'的循环风险面。
  • 作者全文主动披露选择过程（line 337-345/3090-3108/3160）
  • task list 在 Kimi K3.1 Pro、DS1017 评估前固定，两 agent 作事实上的 held-out
  • 去掉 DS1017 后其余 7 agent 保持全 pairwise 顺序（line 3160）——披露倒挂来源
  • Index 明标为 later reporting summary，权重两 suite 相同
裁决（§63 GR 先例）：作者全文主动披露 + 两 agent 在 list 固定后评估（事实 held-out）+ 点名倒挂来源 → 属诚实披露的实验设计选择，非隐瞒漏洞。本仓 backtest_integrity（判单次回测执行期 spoiler）、scoring_integrity（判计分篡改）、transfer_holdout（判模型过拟合迁移）角度不同且本场景已被披露缓解；编译"评测子集选择偏差"门禁将落成无法在外部对象上会拦的玩具（KB-META01 不通过）。→ 加固 KB-AUDIT04/07 指针，不新增不编译。
