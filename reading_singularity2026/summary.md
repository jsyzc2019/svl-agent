## 二、上午 Keynote 与重磅发布

### 1. 李建忠（奇点智能研究院院长、CSDN 高级副总裁）《AI 智能体生态的研究与思考》
- **核心命题**：AI 时代竞争进入"生态竞争"，开发者是最关键变量——"得开发者得天下"。
- **三层生态**：应用生态（基座模型/超级助手/OS 级交互，掌握开发与分发入口）、服务生态（云→MaaS、Agent Runtime）、计算生态（训练/推理芯片、Token 工厂）。
- **AV4C 框架（Agentic V4C）五层**：
  | 层 | 要点 |
  |---|---|
  | 价值层 Value | 工具价值→智能创造价值；开发主体扩至更多人群；交付从软件产品→实际结果；RSI/持续学习拓展创造能力 |
  | 能力层 Capability | 构建 Agent 原生工程栈：运行基础设施、AI Native 工具链、评估/调试/可观测 |
  | 认知层 Cognition | 人类认知→人机认知；GEO/微调/RAG/Context 沉淀知识，专家经验→Skills |
  | 协作层 Collaboration | 人际协作→智能体网络协作；开源技术/组织边界/治理规则需调整 |
  | 分发层 Circulation | 软件分发→智能能力分发；Agent 自动发现/调用/安装能力；付费从"软件"→"结果" |

### 2. 两份年度报告
- **《AI 原生软件研发成熟度模型 AISMM 2027 白皮书》**：5×5 矩阵。横轴五阶段=辅助提效→领域集成→Agent 协同→自主 Agent→自进化工厂；纵轴五要素=基础设施/知识工程/流程工具/组织人才/安全治理。称主流企业处于 **L3–L4**；L3→L4 核心是 **Human-in-the-loop→Human-on-the-loop**（人仍做三件事：定义目标、监控过程、验收结果）；个人提效明显但组织提效难复制，短板在知识工程。
- **《OSDG 2026 全球开源发展报告》**：两大范式变化——① AI Agent 大量参与代码生成/提交，冲击 GitHub 等传统开源协作模式；② 开源内涵从"代码开放"扩展到模型开源/开放研究/开放基础设施/开放评估。含全球开源生态地图与中国活跃度分析。

### 3. 张俊林（新浪微博首席科学家、AI 研发部负责人）《RSI：方法、实践及其局限》
- **历史**：1965"智能爆炸"设想→2001 术语提出→大模型时代引爆（引 Anthropic 预测"2028 年底 60% 概率实现无人值守 RSI"）。
- **方法**：预训练（No Second Run 拆可验证小闭环）、中期训练（MidTool 合成工具调用数据）、后训练（RSI-Dojo 内化"训练模型"能力）；合成数据+RL 环境（BigBang 生成/评估智能体协作、CodeMidas 把开源代码库转 RL 环境）。
- **业界实践（演讲引述，未经独立核验）**：OpenAI GPT-5.6 用于诊断研究失败/优化训练，RSI 指数 Sol 得分 57.9%；Anthropic 称 Claude 编写超 80% 合并代码、训练代码优化最高加速 52 倍（同时声明代码量高估生产率、完全 RSI 未实现、Claude 欠缺研究选题与方向判断）；谷歌 Dream-RSI（历史决策树回放模拟）；MiniMax M2.7 承担 30–50% RL 工作流；Kimi K3 自进化层级知识图谱。
- **微博 AutoHarness**：内外双层循环（内层执行+评估，外层据结果改 Harness）。"恶心广告图检测"案例称一张基础卡跑三天达 99%（对比算法工程师迭代数年）。
- **两大局限**：① 搜索成本（策略空间庞大，耗算力/时间）；② 评价机制（需明确目标+可靠 Verifier，否则模型"钻评价标准空子"而非真提升）。
- **结论**：自称借 AI Coding 历程指出当前 RSI 存在"部分虚假繁荣"，但长期仍是终极方向；以"我是谁，我从哪里来，往何处去"收尾。

### 4. 王纪奎（华为科学家咨询委员会 CTO）《智能世界 2035：从愿景到行动的十大命题》
- **预测**：智能水平达人类当前百倍以上、Token 用量十万级增长、算力攀升+推理成本大降。
- **十大命题**：①自主认知 AGI ②全域随行智能终端 ③走向物理世界（具身/科学智能）④突破算力瓶颈降成本（光电融合、集群算力百倍提升/成本千倍下降）⑤长期记忆存储 ⑥体验为中心连接底座（Agent 间通信量达人与 Agent 十倍）⑦芯片与半导体集成创新（"韬定律"、东数西算）⑧自主演进 Agent OS ⑨AIDC 供电散热（十 GW 规模、十万亿参数、月球/太空算力中心设想）⑩安全隐私可信机制。

### 5. 王富（华为云 Tokens 云服务首席架构师）面向 Agent 时代的 AI Infra
- 模型双趋势（规模扩大 + 轻量化 Flash）→智力从单模型转向群体智能；推理负载 2025 年由 Chat 类转向超长上下文/长程任务。
- 三挑战：超长上下文挤占并发、KV Cache 容量与成本、低时延高并发。
- 华为方案："以存代算"、超节点级内存池 + 灵衢网络(UB)扩展 KV Cache；极简 OS/极简网络/高性能存储支撑 Agent 高频交互。
- 主张：衡量 Agent 集群不能只看启动/运行时间、交互轮次，还要看任务成功率与成本。

## 三、圆桌一：模型、智能体与 Infra 的协同演进（主持：王晗）
- **李建忠**：以施乐 PARC、CUDA（Ian Buck）、AlexNet→cuDNN 为例，论"创新点火者≠生态主导者/价值捕获者"；举 Anthropic 开发者群体、xAI 收购 Cursor、英伟达收购 HuggingFace 为生态入口争夺；"上一个时代是产品经理时代，AI 时代是生态竞争时代"。
- **王纪奎**：用杰文斯悖论论 AI 释放需求；Coding/自动驾驶快因有明确付费意愿；对 RSI 在研发领域应用"不乐观"（研发难形成商业闭环），更看好多模态/具身智能落地。
- **张家兴**：RSI 从三方面拓展 RL（AI 生成任务/强模型辅助弱模型/AI 参与评估）形成更大闭环；AI 接管 ML 实验；产出物从模型→Harness；AI 生成代码使代码从"白盒"变"黑盒"。
- **张俊林**：RSI 仍处初级阶段；两条路线（头部算力领先 vs 小模型+RSI，他更看好后者），大小模型并存；指出"开源看似蓬勃，核心技术反而越来越封闭"，阻碍 RSI 研发。
- **钱城（Dataify CMO）**：合成数据需求将旺盛；三个转变（答得像不像→答得对不对/可追溯、单模态→多模态动态、一次性语料→实时外部反馈）；判断 2027–2028 为 AI 商业化兑现期。
